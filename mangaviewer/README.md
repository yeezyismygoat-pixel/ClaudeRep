# Manga Viewer

e-hentai 의 **한국어 만화**를 휴대폰에서 편하게 보는 안드로이드 앱입니다.
(예전에 VidShelf 안에 있던 만화 기능을 따로 떼어 낸 앱입니다.)

- 다운로드: https://github.com/yeezyismygoat-pixel/ClaudeRep/releases/download/mangaviewer-apk/MangaViewer.apk
- 삼성 보안 폴더 안에 설치하는 것을 권장합니다. VidShelf 와 함께 설치해서 써도 됩니다.

## 화면

| 탭 | 내용 |
|---|---|
| 한국어 | 한국어 만화 전체 목록과 검색, 최근 읽은 만화(이어 읽기). 아래로 내리면 계속 불러옴 |
| 즐겨찾기 | 내 e-hentai 즐겨찾기를 폴더별로 보기 (로그인 필요) |
| 저장 | 휴대폰에 저장한 만화. 인터넷·VPN 없이 볼 수 있음 |
| 설정 | 화면 테마(시스템/라이트/다크), 로그인·로그아웃, 저장 공간 보기·보관 이미지 지우기 |

만화 정보 화면에서 페이지 미리보기(누르면 그 쪽부터 읽기), 태그, 댓글 보기·쓰기(로그인 필요), 즐겨찾기 추가·해제·폴더 옮기기, 휴대폰에 저장, 이어 읽기를 할 수 있습니다.
보기 화면은 세로 스크롤과 한 장씩 넘기기(좌우로 밀기)를 고를 수 있고, 읽은 위치를 기억합니다.

## 로그인

설정 탭(또는 즐겨찾기 탭)의 **e-hentai 로그인 화면 열기**를 누르면 앱 안에 로그인 페이지가 열립니다.
로그인하면 자동으로 돌아옵니다. 안 되면 아이디·비밀번호 입력이나 쿠키 값 입력으로도 로그인할 수 있습니다.
비밀번호는 저장하지 않고 로그인 쿠키만 휴대폰 안에 암호화해서 저장합니다.

## 연결이 안 될 때

국내에서는 e-hentai 접속이 막혀 있습니다. **보안 폴더 안에** VPN 앱(예: 1.1.1.1)을 설치해 켠 뒤 다시 시도하세요.
일반 공간에서 켠 VPN 은 보안 폴더 안의 앱에 적용되지 않습니다.

## 만드는 방법 (개발용)

`android/` 는 외부 라이브러리 없는 안드로이드 프로젝트입니다. 앱 안의 작은 웹 서버(이 휴대폰에서만 접속, 포트 8909)가
`web/` 의 화면을 보여 줍니다. `manga-viewer` 브랜치에 올리면 GitHub Actions 가 APK 를 만들어 위 주소에 올립니다.
