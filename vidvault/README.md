# VidVault

내가 가진 **성인용 영상·사진(합법, 개인 소장)** 을 위한 개인 보관함 앱입니다.
VidShelf 와 같은 화면을 쓰지만 패키지(`app.vidvault`)·데이터·아이콘·배포 링크가 따로라서 둘을 함께 설치할 수 있습니다.

- 다운로드: https://github.com/yeezyismygoat-pixel/ClaudeRep/releases/download/vidvault-apk/VidVault.apk
- **개인용 전용**: 이 앱은 구글 플레이스토어에 올리지 않습니다 (플레이스토어는 성적 콘텐츠 앱을 허용하지 않음).
- 성인 전용: 사람의 나이는 18세 이상일 때만 보이고, 나이 구분은 18~19세부터입니다.
- 인터넷에서 영상을 받거나 사람 정보를 찾아오는 기능은 없습니다. 직접 넣은 MEGA·iCloud 링크만 씁니다.

## 사생활 보호 (설정 → 사생활 보호)

| | |
|---|---|
| 앱 잠금 | 앱을 열 때, 그리고 정한 시간(바로·30초·1분·5분)보다 오래 다른 앱에 다녀오면 지문·얼굴 또는 휴대폰 PIN 으로 잠금 해제 |
| 화면 캡처 막기 | 스크린샷·화면 녹화 차단, 최근 앱 목록에서 내용 가림 (기본 켬) |
| 썸네일 흐리게 | 목록·홈·사람·숏폼 표지를 흐리게. 한 번 누르면 그것만 보이고, 오른쪽 위 눈 버튼으로 모두 보기 (기본 켬) |
| 빠르게 숨기기 | 오른쪽 위 방패 버튼 또는 휴대폰 뒤집기(선택) → 재생을 멈추고 평범한 시계 화면. 잠금을 풀어야 돌아옴 |

## 구성

- `android/` – 안드로이드 앱 (WebView + 앱 안 작은 웹 서버 127.0.0.1:8919)
- `static/` – 화면 (app.js, style.css, index.html)
- `server.py`, `install.sh` – PC/Termux 용 서버 (화면 테스트용)
