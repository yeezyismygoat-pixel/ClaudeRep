# VidShelf 플레이스토어 출시 안내

앱 쪽 준비(안드로이드 15 대응, AAB 빌드, 보안 정리, 개인정보처리방침 페이지)는 끝났습니다.
아래는 **직접 하셔야 하는 일**을 순서대로 적은 것입니다.

## 1. 서명 키 등록 (가장 먼저, 한 번만)

플레이스토어에 올리는 파일은 **항상 같은 키**로 서명해야 합니다. 키 파일을 잃어버리면 앱을 더 이상 업데이트할 수 없으니, 받은 파일 두 개(`vidshelf-new.jks`, `VIDSHELF_KEYSTORE_B64.txt`)는 휴대폰과 다른 곳(구글 드라이브 등)에 **꼭 따로 보관**하세요.

1. GitHub에서 이 저장소를 엽니다 → 위쪽 **Settings**
2. 왼쪽 **Secrets and variables → Actions**
3. **New repository secret**
   - Name: `VIDSHELF_KEYSTORE_B64`
   - Secret: `VIDSHELF_KEYSTORE_B64.txt` 파일 안의 글자 전체를 복사해 붙여넣기
4. **Add secret**

등록한 뒤 처음 만들어지는 APK는 서명이 바뀌어서, 폰에 깔린 VidShelf를 **한 번 지우고** 새로 설치해야 합니다.
지우기 전에 앱 **설정 → 백업 / 복원 → 백업 파일 저장**을 먼저 하고, 새로 설치한 뒤 **백업에서 복원**하세요.

- 키 비밀번호: `vidshelf` (키 이름 `vidshelf`)
- 키 지문(SHA-256): `5D:75:2B:A3:89:DE:F3:BC:5D:F6:B0:64:21:28:C2:4F:10:C8:4B:FC:4B:90:CD:CE:EE:3D:C4:22:3E:01:F1:A9`

## 3. Play Console 준비

1. **개발자 계정** 만들기 (등록비 25달러, 한 번). 본인 확인에 며칠 걸릴 수 있습니다.
2. **앱 만들기**: 앱 이름 `VidShelf`, 기본 언어 한국어, 앱(게임 아님), 무료.
3. **개인 계정이면 비공개 테스트가 먼저 필요**합니다: 테스터 **12명 이상이 14일 연속** 설치한 상태를 유지해야 정식 출시(프로덕션) 신청이 열립니다.

## 4. 올릴 파일

GitHub 저장소의 **Releases → VidShelf APK** 에서 `VidShelf.aab` 를 받아 올립니다. (`VidShelf.apk` 는 폰에 바로 설치하는 용도)
처음 올릴 때 **Play 앱 서명**을 쓰겠냐고 물으면 “Google에서 앱 서명 키 관리(권장)”를 고르면 됩니다. 위 1번 키는 ‘업로드 키’가 됩니다.

### 데이터 보안 설문

- **데이터를 수집하거나 공유하나요?** → “아니요”
  - 이유: 모든 정보가 폰 안에만 있고 개발자 서버로 아무것도 보내지 않습니다.
  - 참고: MEGA·iCloud 연결은 사용자가 넣은 링크로 폰이 그 서비스에 **직접** 접속하는 것이라, 보통 ‘수집’으로 보지 않습니다. 심사에서 다르게 판단하면 “사용자 생성 콘텐츠 – 사진·동영상 / 사용자 요청으로 전송” 정도로 고치면 됩니다.
- **전송 중 암호화** → 예 (바깥 연결은 모두 https)
- **데이터 삭제 요청 방법** → 앱을 지우면 모든 정보가 삭제됨

### 권한 설명 (사진·동영상 권한 선언)

Play Console이 `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO` 사용 이유를 물으면:

> VidShelf는 기기에 있는 사진과 동영상을 폴더·태그·사람별로 정리하고 재생하는 미디어 라이브러리(갤러리) 앱입니다. 사용자가 고른 폴더의 모든 사진·동영상을 목록으로 보여 주고, 태그·별점·즐겨찾기를 붙이고, 중복 파일을 찾는 것이 앱의 핵심 기능이므로 사진 선택 도구로 몇 장만 고르는 방식으로는 기능을 제공할 수 없습니다. 미디어는 기기 밖으로 전송되지 않습니다.

영문이 필요하면:

> VidShelf is a media library (gallery) app that organizes and plays all photos and videos on the device by folder, tag, and person. Listing every item in the user's chosen folders, tagging, rating, and finding duplicates are core features that the photo picker cannot provide. Media never leaves the device.

`MANAGE_MEDIA`(미디어 관리) 이유:

> 사용자가 앱에서 즐겨찾기를 바꾸거나 파일을 휴지통으로 옮길 때, 매번 확인 창을 띄우지 않고 기기 갤러리와 맞추기 위해 사용합니다. 사용자가 설정에서 직접 켜는 선택 권한입니다.

심사용 **동영상**(30초 정도)을 요구하면: 앱 열기 → 미디어 탭 목록 → 사진·영상 열기 → 태그 붙이기 → 중복 찾기 화면을 화면 녹화하세요. **평범한 풍경·여행 영상**만 나오게 해 주세요.

## 6. 스토어 등록 정보 초안

**짧은 설명 (80자 이내)**
> 폰의 영상과 사진을 태그·사람별로 정리하고, 숏폼처럼 넘겨 보는 미디어 보관함

**자세한 설명**
> VidShelf는 휴대폰에 쌓인 영상과 사진을 깔끔하게 정리해 주는 미디어 보관함입니다.
>
> • 태그·사람·날짜·길이·화질로 거르고, 자주 쓰는 조건은 저장해 두기
> • 내 영상을 숏폼처럼 위아래로 넘겨 보기
> • 이어 보기, 연속 재생, 두 번 눌러 10초 이동, 꾹 눌러 2배속
> • 중복 영상·사진 찾기, 정리 안 된 항목 모아 보기
> • 시청 기록과 통계
> • MEGA 공유 폴더·iCloud 공유 앨범도 같은 목록에서 보기
>
> 모든 정보는 휴대폰 안에만 저장됩니다. 광고와 회원가입이 없습니다.

**스크린샷**: 휴대폰 화면 2~8장. 풍경·여행·음식 같은 **평범한 예시 영상·사진**으로 찍으세요. 실제 인물의 사진이나 성인 느낌의 이미지는 넣지 마세요.

## 7. 남아 있는 위험

- **MEGA 파일 ‘휴대폰에 저장’ 기능**은 그대로 두기로 하셨습니다. 심사에서 ‘저작물 무단 다운로드’로 거절되면, 그 기능만 끄는 버전을 바로 만들 수 있으니 거절 메일을 보여 주세요.
- **iCloud 공유 앨범**은 Apple이 공개하지 않은 방식으로 불러옵니다. Apple이 바꾸면 갑자기 안 될 수 있습니다(심사 문제는 아님).
- 이름 `VidShelf`, 패키지 이름 `app.vidshelf` 가 이미 쓰이고 있으면 앱 만들기 단계에서 막힙니다. 그때 알려 주시면 이름을 바꿉니다. (패키지 이름은 출시 뒤 바꿀 수 없습니다)
